CoHabit

Projet d'équipe · 2026

Application web de gestion de colocation : liste de courses, tâches, calendrier, dépenses partagées et membres. Projet mené à cinq en Scrum, avec git-flow et une revue de code obligatoire pour chaque pull request.

Scan de tickets de caisse par IALa photo du ticket est envoyée à un modèle de vision via l'API Groq. La réponse JSON est contrôlée, puis les articles achetés et le total sont proposés à l'utilisateur, qui valide.

J'ai participé à toutes les étapes : analyse, API REST en Java sur une base Oracle, et front-end.
